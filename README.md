# 2026 NCHU Robot Competition

ROS 2 Humble container for the 2026 NCHU Robot Competition.

---

# Project Structure

```text
.
├── compose.yaml              # Docker Compose configuration
├── Dockerfile                # Docker image definition
├── requirements.txt          # Python dependencies
└── ros2_ws
    ├── src
    │   ├── custom_interface
    │   ├── port_pose_estimator
    │   ├── py_gripper
    │   ├── optoforce_driver  # Clone from keep5lience5555-crypto
    │   ├── tm2_ros2          # Clone from Techman
    │   ├── realsense-ros     # Clone from Intel
    |   └── other packages...
    ├── build                 # Generated by colcon
    ├── install               # Generated by colcon
    └── log                   # Generated by colcon
```

The `build`, `install`, and `log` directories are generated by `colcon` and should not be committed to Git.

# Setup

## 1. Clone the repository

```bash
git clone https://github.com/Jun-yuChen/2026_NCHU_robot_competetion.git
cd 2026_NCHU_robot_competetion
```

---

## 2. Clone required ROS packages

Clone the required external repositories into `ros2_ws/src`.

### Techman ROS 2 Driver
```bash
git clone https://github.com/TechmanRobotInc/tm2_ros2.git
```

### Intel RealSense ROS Driver
```bash
git clone https://github.com/IntelRealSense/realsense-ros.git
```

After cloning, the workspace should look like

```text
ros2_ws/src/
├── custom_interface
├── port_pose_estimator
├── py_gripper
├── optoforce_driver
├── tm2_ros2
├── realsense-ros
└── ...
```

---

## 3. Build the Docker image

```bash
docker compose build
```

---

## 4. Start the development container

Allow Docker to access the X server.

```bash
xhost +local:docker
```

Run the container.

```bash
docker compose run --rm --name ros2_dev ros2
```

To open another terminal inside the running container:

```bash
xhost +local:docker
docker exec -it ros2_dev bash
```

---

## 5. Build the ROS workspace

Inside the container:

```bash
source /opt/ros/humble/setup.bash

cd /ros2_ws
colcon build --symlink-install

source install/setup.bash
```

---

## 6. Clean the workspace

If the build cache becomes inconsistent:

```bash
rm -rf build/ install/ log/
```

Then rebuild:

```bash
colcon build --symlink-install
```

# Package Overview

| Package                 | Description                                                                                                |
| ----------------------- | ---------------------------------------------------------------------------------------------------------- |
| **custom_interface**    | Custom ROS 2 message and service definitions used by the project.                                          |
| **port_pose_estimator** | Runs the RealSense camera, YOLO object detection, and estimates the 3D pose of the target port.            |
| **py_gripper**          | Controls the Techman robot and gripper. Performs robot motion planning based on the estimated target pose. |
| **optoforce_driver**    | Driver for OptoForce 6-axis FT sensor. Includes a ROS node for running the sensor.                         |
| **tm2_ros2**            | Official ROS 2 driver for the Techman robot.                                                               |
| **realsense-ros**       | Official ROS 2 wrapper for Intel RealSense cameras.                                                        |

# Running the System

Open a new terminal inside the Docker container.

```bash
source /opt/ros/humble/setup.bash
source /ros2_ws/install/setup.bash
```

Run each component in a separate terminal.

## Launch the Techman robot

```bash
ros2 launch py_gripper tmr_grip_launch.py
```

This starts the Techman robot driver and gripper interface.

---

## Launch the camera and port pose estimation pipeline

```bash
ros2 launch port_pose_estimator tmr_depth_launch.py part:=server1
```

This launches:

* Intel RealSense camera
* Chang's port pose estimator

After launch this, you can monitor the camera stream at <http://localhost:8091/>.

---

## Start the robot command node

```bash
ros2 run py_gripper arm_cmd --ros-args -p part:=server1
```

The motion node subscribes to the estimated target pose and commands the robot to move accordingly.

---

## Launch the Optoforce FT sensor

```bash
ros2 run optoforce_driver optoforce_node --ros-args -p port:=/dev/ttyACM0
```

After that you can monitor the force reading in rqt plot with 

```bash
ros2 topic echo /optoforce/wrench
```

or

```bash
ros2 run rqt_plot rqt_plot
```

Note that this FT sensor drifts after some time so it is recommend to restart the sensor everytime you need it.

---

## Start stream control (PVT control) node
```bash
ros2 launch stream_control stream_launch.py 
```
This node allows the robot to receive PVT command.

## Start spiral searching and insertion node
```bash
ros2 launch stream_control spiral_search_launch.py 
```
This node will do surface touch, z-force control, spiral search and peg insert.

# Typical Workflow

1. Start the Docker container.
2. Launch the Techman robot.

## Using Yolo to move the robot
1. Launch the port pose estimator.
2. Command the robot to move to target and lower down the arm.

## Insertion with spiral searching
1. Launch the FT sensor.
2. Launch the stream control node.
3. Launch the node for spiral searching with z-force controller.

# Rebuilding After Code Changes

After modifying source code:

```bash
cd /ros2_ws

colcon build --symlink-install

source install/setup.bash
```

If unexpected build errors occur:

```bash
rm -rf build/ install/ log/

colcon build --symlink-install
```
